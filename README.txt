시간이 쌓이는 그 곳 · GPS 음원 테스트

사용 방법
1. 휴대폰에서 HTTPS 주소로 index.html을 엽니다.
2. 처음 한 번만 “1번부터 GPS 테스트 시작” 버튼을 누릅니다.
3. 1번 수원문화재단 좌표에 도착하면 1번 음원이 자동 재생됩니다.
4. 이후 2번부터 8번까지 해당 좌표에 도착할 때마다 다음 음원으로 자동 전환됩니다.
5. 장소를 벗어나도 현재 음원은 계속 재생되며, 다음 장소에 도착할 때만 페이드 전환됩니다.
6. 음원은 반복재생하지 않습니다.

주의
- 브라우저의 오디오 정책 때문에 최초 시작 버튼은 한 번 눌러야 합니다.
- 이후 2번~8번 버튼을 따로 누를 필요가 없습니다.
- GPS는 HTTPS 환경에서 테스트하는 것이 좋습니다.
- 장소 진입 반경은 약 45m입니다.
