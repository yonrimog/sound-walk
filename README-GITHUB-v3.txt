재생 방식 v3

- 브라우저 영구 기록을 사용하지 않습니다.
- 페이지를 새로 열면 재생 상태가 새로 시작됩니다.
- 페이지를 연 뒤 처음 만나는 GPS zone이 1번이면 1번이 재생됩니다.
- 처음 만나는 zone이 2~9번이면 그 번호가 바로 재생되고, 그 페이지가 열려 있는 동안 1번은 무시됩니다.
- 2~9번은 이후 순서와 관계없이 해당 zone에 들어갈 때 재생됩니다.
- 같은 zone 안에서 GPS가 계속 움직이는 동안에는 반복 재생하지 않습니다.
- 다른 zone으로 나갔다가 다시 들어오면 해당 음원이 다시 재생됩니다.
- '새로 시작' 버튼을 누르면 페이지 세션을 초기화합니다.
